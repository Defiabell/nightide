# 夜潮 Nightide

守灯人的长夜——对称自动战争 + 局内轮抽的单机网页游戏。

Nightide is a symmetric auto-war browser game: pick a faction, draft your build, run an economy, and bring down the other side's lighthouse. No download, a match takes a few minutes.

**▶ [在线游玩 / Play now](https://defiabell.github.io/nightide/)** · **[itch.io](https://defiabell.itch.io/nightide)**

![夜潮 对战画面](docs/screenshot.png)

## 三个阵营，随机的对手

- **经典（发条匠）**——工厂流水线：金币、木材、矿石三线经济，兵种全面。
- **野兽（荆棘女巫）**——活体荆棘：快而脆的狼群与飞蛾，铺场如潮。
- **亡灵**——纯魂能经济：尸兵不占编制，靠击杀与腐土回魂；骨冢回收阵亡赏金、疫地腐蚀大地、附身夺取敌军，前排是缝尸而成的墓骸巨尸，随军的疫尸是一块会走路的疫地。

阵营由你自选，**敌方阵营每局随机**并在开局揭示。地图、野兽巢穴、抽卡序列全部随种子生成，每局都是新图。

## 模式与难度

- **经典对战** / **雾夜对战**（战争迷雾，靠灯塔与部队照亮视野）/ **防守模式**（守住灯塔，抵御不断升级的夜潮巢穴）
- **每日挑战**：全球同一颗种子，比通关速度
- 三档难度：困难档的 AI 拿双倍经济、会升级建筑、被压制时自动扩产能，还会记住你上一局的打法
